# Queen 读取委派复测（2026-09-15）

结论：改成“工蜂先取证、Queen 风险复核”并精简入口技能后，这一组读取型任务的 Queen 总 token 比新版直接组减少 **60,942（5.25%）**，耗时增加 **62.01%**。这是单次小幅正向结果，不足以证明稳定收益、严格质量等价或大任务表现。

## 修改内容

- Queen 保留用户需求理解、关键设计决策和最终验收；有界只读调查可以先交工蜂，不要求 Queen 先完成同一轮全面调查。
- 工蜂先搜索、批量读取，再交一份包含版本、范围、证据定位和未确认项的证据包；普通进展不逐步回传。
- Queen 独立复核会改变决策的关键源码和证据缺口，避免重复整轮探索；代码变更仍须审查实际 diff 并独立验证。
- 减少不必要的提示、检查轮询和重复规则加载；普通原生 Luna 派发无需先加载外接模型参考文档。模型设置或失败恢复时仍按需读取。
- 主指标明确为包含缓存输入的 Queen input + output；工蜂用量、未缓存输入代理值、传输字节和耗时分开记录。

这次改的是技能与文档，没有修改 worker 控制器运行代码。当前被测 SKILL 的 SHA-256 为 `a78e1c9e3480879c17567a6e829031931585342cd12ce16c43584b568e7b5730`，旧版为 `046f14dfc11eed876557128d742b0bfb3809451dc012d7bd8b2dbb0b969084bc`。入口从 17,211 缩至 9,637 UTF-8 字节；字节减少本身不是模型 token 收益。

## 同条件新对照

两名独立、无历史对话继承的 Queen 都使用 **GPT-6 Astra / max**。直接组自行高效搜索和选读；委派组使用一名原生 **GPT-5.6 Luna / max**，然后由 Queen 独立复核。两组均读取新版技能，不读取旧结果或对方报告。

固定源码提交为 `4e2cbdf48eef1e17d3aeb86781b415bf9081dfa3`，7 个源码/测试文件合计 5,896 行，文件哈希与首轮完全一致。共同任务是回答从派发、排队、模型保持到验证、停止和 fork 的 12 个控制行为问题。允许高效搜索、局部读取，不强制直接组逐字读完全部文件。只读、不执行运行时场景，两组并行，仅此一对，未挑选或丢弃失败重跑。

主指标减少 **5.25%**；次要代理值减少 **19.02%**，不能替代主指标，更不是已核实的账单或账户配额节省。总量是会话各轮累计，并非独有源码 token：重复输入和缓存输入都包含其中。reasoning 是 output 的子集，不再次累加。

Luna 单独消耗 input 4,087,989（cached 3,915,520）、output 20,141（reasoning 12,160），total **4,108,130**，39 次工具调用。工蜂不计入 Queen 指标；合计为 **5,208,325**，高于直接组，所以这里没有“整体 token 更少”的结论。没有外接 DeepSeek/GLM 实测，不据此推断其收益。

计数来自每个参与会话最后的主机 token_count 累计记录，并与独立 token_usage_record 的 thread_token_usage 对齐；三者一致。包含 Queen 的技能读取、派发、6 次等待、1 次补证请求、复核和最终报告。两组均不包含实验组织者的准备、评分及报告成本；本结论不是整个外层聊天的净 token 测量。

## 质量核对

实验开始前固定 12 项验收清单。两份报告均覆盖 12 个主题；Queen 之外的实验组织者独立核对关键实现，没有发现第 3、9、10、12 项上的虚假安全保证：单 agent 锁不是跨目录锁，检查通过不是无条件验收，abort 回执不是远端已停止，fork 不是独立文件系统。

按清单细节逐项给分，两组各 **11.5/12**，其余项目均 1 分：

- 直接组第 12 项得 0.5：说明共享目录和每 agent 锁的限制，但没有明确写出“创建 fork 时父会话须 idle”。
- 委派组第 6 项得 0.5：说明连续 retry 120 秒升级和普通超时行为，但没有明确写出“单次等待上限 55 秒”。

因此，核心调查结果可用，但不能称为满分、逐细节等价或已证明没有质量损失。未改写封存报告，也没有为这些不改变核心结论的细节重跑。委派 Queen 在最终提交前的一次补证已计入用量；实验组织者没有要求修复轮次。

源码和测试定位是静态证据，不是两组实际执行过测试、恢复、停止或并发场景的证明。

## 局限与验证

单样本、模型随机性、缓存行为、并行资源竞争和输出详略均可能影响结果。直接组使用大量展开的绝对路径链接，最终消息显著更长，是已记录的格式混杂因素；不能把所有差值都归因于委派。两组最终报告都没有严格控制到同一长度，未事后删改输出或扣除其 token。下一步需多次配对、交替顺序并统一引用格式，在不同读取/实现任务上验证中位数、范围、质量和耗时，不能据这一对承诺固定节省比例。

本次修改的本地离线套件：**115 通过、1 跳过、0 失败**；跳过项需要 `DEEPSEEK_LIVE_PREREQ=1`。技能/插件结构校验通过。这与上述只读模型比较是两项不同验证，未另行调用 DeepSeek/GLM。源码功能文件未变，未改写历史报告。
